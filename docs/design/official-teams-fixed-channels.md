# 团队管理与个人固定渠道改造方案

实施基线为官方 v1.8.7.2。

以实施时官方发布的最新正式版为基线，保留 DreamCanvas 的 Lumi 图片、Lumi 视频两套协议和个人固定渠道，用「团队管理」替代旧的「公司管理」。员工通过官方注册和邀请流程加入团队，个人创作使用自己的 New API Key。

## 个人固定渠道与积分

- 平台管理员配置固定渠道的 New API 地址、模型和使用权限。本次部署只配置固定渠道，通用渠道保持未配置。模型列表只展示当前账号获准使用的固定渠道模型。Lumi 图片和 Lumi 视频继续沿用各自的协议实现。
- 员工从所在组织的负责人处取得 New API Key，在个人设置为已授权的固定渠道填写、更新或移除 Key。后端在个人创作提交时校验账号、渠道权限和凭据，使用该账号为该渠道填写的 Key 请求配置好的 New API。凭据缺失、失效、额度耗尽或没有模型权限时，生成失败。固定渠道请求禁止回退至通用渠道或共享 Key。
- 用户可自行调整自己的 DreamCanvas 个人积分，沿用个人空间原有积分扣费流程。调额接口只更新登录账号的个人积分。团队所有者主动划入团队资金池仍走官方原有入口。New API 记录该 Key 的实际用量，并按自身额度和权限控制模型访问。即使用户把个人积分调高，没有可用于该请求的 Key 也无法生成。
- 自调积分入口位于「个人设置 → 渠道与存储 → 固定渠道」。用户保存 Key 后可提交调整。后端先用该 Key 请求所选渠道的 `GET /v1/models`，只有 HTTP 200、业务响应未报告失败且返回至少一个带 ID 的模型才更新余额。该检查只读取模型列表，具体模型能否实际生成由生成请求确定。将来开放面向个人用户的充值或通用渠道前，需先确定自调积分与充值权益的规则。

## 后台团队管理与官方团队空间

- 「后台 → 团队管理」接替旧的「公司管理」。站点管理员可查看官方团队列表、团队所有者和成员。本期仅提供查看入口，团队成员与其他账号一样继续显示在「后台 → 用户管理」。站点管理员的后台查看权限沿用站点管理权限，团队空间内的访问权限仍按官方成员角色判定。
- 工作台的团队空间沿用官方的团队创建、邀请与接受、成员权限、积分划拨、资产和任务规则。团队钱包的余额和扣费继续由官方流程处理。个人调额和个人固定渠道 Key 仅用于个人空间，团队内分配的积分仍在团队空间使用。
- 移除旧公司管理入口、自建公司成员关系及公司管理员给员工分配个人积分的流程。固定渠道的授权改用现有用户分组和渠道授权，团队成员身份本身不授予固定渠道权限。员工自行注册，再接受官方团队邀请。旧公司代开户后续另议，实施按全新开发数据库验收，无需设计旧数据迁移。

## 实施验收

1. 用官方正式版核对团队入口与契约。验证注册后接受邀请、查看成员、团队积分划拨、资产访问和官方支持的任务流程。
2. 站点管理员能在后台看到团队和成员。普通账号无法访问该后台入口，站点后台查看权限也不会改变团队空间权限。团队成员仍出现在用户管理。
3. 将账号个人积分调高后，验证无 Key、无渠道授权、Key 失效和上游额度不足时，后端都拒绝生成。使用有权限且有额度的 Key 时，验证 Lumi 图片和视频任务各自命中预期固定渠道，New API 用量归到该 Key。
4. 验证调额仅作用于当前账号的个人积分，团队钱包和其他账号的余额保持原值。验证个人 Key 不作为团队任务的凭据。

旧公司开户和员工划拨的历史记录见 [旧公司方案](company-fixed-channel.md)。
